# Cine
## Functions
#### 
1. Search
2. Infinite discovery
3. Categories
4. Continue watching
5. Highlight
## How it works
####
Uses The Movie Database (themoviedb.org) to display information and pictures about movies and series.
Uses Vidcore (vidcore.net) to gather the movies with iframe.
